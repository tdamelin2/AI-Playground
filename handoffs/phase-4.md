## For Tim
This phase builds the players' minds and the connections to the five AI companies, but every test uses a pretend AI (the "fake adapter", canned answers that cost nothing). Nothing is spent and no real AI is called.
- The work is split between two coders: one builds the "plumbing" (talking to each company, counting money, the spending limit, retries, saving and crash safety), the other builds the "mind" (values, memory, the three thinking speeds, choice records, the weekly reflection) and what you see on screen.

C4 Money (A)
- `llm/prices.py cost_usd(usage, prices) = (input*I + cache_write*CW + cache_read*CR + output*O)/1e6` (Decimal inside, float out). Example: I 2, CW 2.5, CR 0.1, O 10; input 1000, cache_write 200, cache_read 300, output 150 (100 visible + 50 thinking) -> (2000 + 500 + 30 + 1500)/1e6 = $0.00403.
- `upper_bound_usd(request, role) = ceil(chars(fixed+slow+current)/chars_per_token) * max(I, CW) + max_output_tokens * O` (/1e6). Example: 4000 chars, max_output 500, I 3, CW 3.75, O 15 -> (1000*3.75 + 500*15)/1e6 = $0.01125.
- `SpendLedger(cap_usd, warning_share, total_usd)`: `reserve(key, bound) -> bool` (false when total + all outstanding reservations + bound > cap; equality allowed), `settle(key, cost)`, `release(key)`, `warning` (total >= warning_share*cap), `total_usd`. Example: total 0.90, reserved 0.06, bound 0.05, cap 1 -> reject (1.01 > 1); total 80, cap 100 -> warning true.

C5 CallBroker (A, llm/broker.py)
- `CallBroker(db: RunDB|None, models, ai_cfg, adapters: dict[provider, Adapter], ledger, sleep=time.sleep, wall=time.time, replay=False, wait_hook=None)`.
- `run(pipelines: dict[str, Generator[LLMRequest, LLMResult, T]]) -> dict[str, T]`: starts every generator, sends each yielded request to a ThreadPoolExecutor (max_parallel), sends each LLMResult back into its generator, returns when all generators have returned. Different players overlap; one player's requests are sequential (Noticer -> Advisor -> main). Results are fed back on the calling thread; the returned dict is applied by the caller in player_order, never completion order. While waiting it calls `wait_hook()` every wait_hook_seconds. Workers get detached request/role data only (no World, RNG, SQLite, pygame).
- Per attempt, in order: (1) reuse: `db.find_ai_call(attempt_key)` returns a stored row -> rebuilt result, `reused=True`, no adapter call, no spend, no waits; (2) `replay=True` and no row -> `ReplayMissingError`; (3) `ledger.reserve`; refused -> status budget_blocked, nothing sent, and after the other in-flight calls of the batch finish, `RunPaused("spend_cap")`; (4) send; (5) write one ai_calls row (prompt_json = the three layers + schema name, reply_json, model_version, all token columns, cost_usd, duration_ms, status, details_json {key, attempt, purpose, role, model, settings}) and one spend row (cumulative) on the calling thread immediately, before the reply is used.
- Rules: invalid JSON or Pydantic failure -> retry once (format_retries) then status format_error; refusal (adapter `refused` or reply text matching break_character_phrases) -> no retry, status refusal; NetworkError/RateLimitError -> waits retry_wait_seconds[i] then retry, 3 retries (4 attempts), then `RunPaused("network")`; NetworkError on a call whose wall duration > sleep_gap_seconds -> `RunPaused("sleep")` immediately. A model is never switched. Every physical attempt has its own row.
- FakeAdapter(script=None, delays=None, failures=None, bill=False, gate=None): model_version "fake-1"; usage input = ceil(chars/4), output = ceil(len(reply)/4), thinking 0, cache_read = ceil(len(fixed+slow)/4) when the same player+family already sent identical fixed+slow, else 0; auto mode builds a valid instance of `request.schema` from `meta["fallback"]` with fixed text; `script[(player_id, purpose)]` = list of dicts or raw strings popped per attempt (bad replies can be scripted); `failures[(player_id, purpose)]` = list of "network"|"rate_limit"|"refusal"|"sleep" consumed per attempt; `delays[(player_id, purpose)]` seconds; `gate` = threading.Barrier/Event hooks for overlap tests; `calls` counter per key. Deterministic and thread-safe.
- `FakeEmbedder(dims=64)`: sha256 of each lowercase word -> bucket, L2-normalised; same text -> same vector; empty text -> zero vector. Embedding cache: in-memory dict, plus `runs/<run>/embeddings.sqlite` (key sha256(model+text)) for persisted runs; snapshots hold text only.

- `RunPaused` during a tick: the Simulation discards the partial tick's events (truncate to the tick-start index), sets `sim.broken = True`, keeps the ai_calls/spend rows already written, and re-raises. A broken sim refuses `run()`. Persisted runs continue only via `recover()` (snapshot + replay reusing stored replies), which rebuilds the last complete tick and re-runs the interrupted tick with the stored replies. Headless/resume print `Run paused: <reason>. Continue with: uv run python main.py resume <run>` and exit 4. No event is written for a pause.
- Recovery: `recover()` builds the broker with `replay=True` for the verified tail, then `replay=False` (reuse-first still applies), so no stored reply is ever requested again (AC-19 fake call counts).

C9 Minds (B)
- Schemas (minds/schemas.py, all `extra="forbid"`): `SelfLabel(served:list[str]<=4, violated:list[str]<=4, direction: Literal["toward","against"])`; `FastReply(thought:str, action: ActionRequest-shaped, self_label, expected_feel:int[-10,10], needs_more_thought:bool)`; `Option(action, serves, violates, feel_now:int[-10,10], feel_later:int[-10,10], relationships:str, villagers:str, uncertainty: low|medium|high)`; `SlowReply(thought, options: 2..4 Option, choice_index:int, trade_off:str, self_label)`; `NoticerReply(reads: list[{person, feeling, intent, uncertainty}] <=4)`; `AdvisorReply(advice:str, recommended_kind:str, past_patterns:list[str]<=5)`; `RankingReply(entries: list[{value_id, weight:float}])`; `InventedValue(name, definition, priority:float>0, conflicts:list[str], observable_behaviour:str)`; `ReflectionReply(requested_changes: dict[str,float], cause_event_ids:list[int], invented_values: list[InventedValue] <=2, identity:str, knowledge_updates: list[{subject, claim, confidence:[0,1]}] <=5, rolling_summary:str, insights: list[{decision_key, insight}])`. - Values (minds/values.py): `VALUE_IDS` library order friendship, work, religion, family, respect_others, respect_self, honesty, loyalty, fairness, generosity, security, independence, power, curiosity (tie-break order everywhere, then invented values by creation).
  - `repair_initial_weights(entries) -> (weights, problems)`: unknown/duplicate/non-finite/negative dropped, missing added at weight 1 (each a problem); ranked by weight (ties library order); top 5 = core; projection `w_i = min(upper_i, max(lower_i, lambda*raw_i))` with core [10,25], background [1, min core], lambda solved so the sum is 100 (abs err < 1e-6); all-zero/unusable -> fallback: core 5 by library order at 10, background 50/9 each. Examples: `[14]*5+[4]*3+[3]*6` (library order) -> unchanged, problems []; all 14 at 100/14 -> friendship, work, religion, family, respect_others = 10 each, others 5.5556 each, problems ["core_below_min"]. Repairs emit `value_repaired`. Initial weights write 14 value_history rows with game_week 0 and old_weight NULL.
  - `reflect(weights, requested_changes, invented) -> (new_weights, clipped, invented_status)`: clip each request to +/-10, apply, append an accepted invented value at raw weight = priority, then floor-lock rescale: find lambda with `sum(max(1, lambda*raw_i)) = 100`; core = top 5 after (no 25% cap). Examples: (a) AC-12 sample, friendship +30 -> clipped +10 -> raw 24, total 110 -> friendship 21.8182, other core 12.7273, the 4s 3.6364, the 3s 2.7273. (b) friendship 20, work 20, honesty 15, fairness 15, family 10, curiosity 8, security 5, power 1, the other 6 at 1; curiosity +15 (clipped +10), work -4 -> the 7 values at 1 stay 1, the rest (raw 99) scale to 93: friendship 18.7879, curiosity 16.9091, work 15.0303, honesty 14.0909, fairness 14.0909, family 9.3939, security 4.6970; core = friendship, curiosity, work, honesty, fairness. (c) `[87]+[1]*13`, +10 to the first -> raw 97 + 13 -> result `[87]+[1]*13`.
  - `validate_invented(v, weights) -> str|None` (reason): name/definition mention a banned word or real_world_words, grant abilities (ability_phrases), or duplicate an existing value (name equals an id/name case-insensitive) -> rejected; at most weekly_invention_limit accepted per week (first valid only); rejections emit `invention_rejected`.
- Memory (minds/memory.py): `MemoryItem(id, tick, kind, text, importance: 0..1)`; `score = recency_weight * 2**(-(now - tick)/half_life) + importance_weight * importance + relevance_weight * (1 + cos)/2`; `retrieve(stream, query, now, limit, embedder)` sorted by score desc, ties (tick desc, id asc); `recent(stream, n)` newest n. Example: two items at the same tick and importance with vectors [1,0] and [0,1], query [1,0] -> the first ranks higher. Hooked decisions use recent(hooked_memory_size) and make zero embed calls. Items are captured at each decision from that decision's report (sounds, interrupts, players/villagers/dogs/structures seen, body/feeling when changed) and from the previous action's outcome and mistakes; never from hidden truth (no KnowledgeEntry.true, poison kinds, exact X, other players' inventories). Rolling summary changes only in a successful weekly reflection.
- Prompts (minds/prompts.py): `opening_guide(name, villager_names)` = gameplay.md text exactly, names filled; day-0 bootstrap ranking prompt = guide + value library + ranking instruction (separate call, purpose ranking, before the first action). After it, layer 1 per player and family (player: guide + value library + action list "things you can do" + both reply formats; noticer; advisor) is byte-identical for every call of that player+family in the run (`fixed_digest(pid, family)`); layer 2 = identity, current weights with core marked, relationship words (trust/anger as words, human names), knowledge book (subject, claim, confidence only), rolling summary; layer 3 = sense report text, memories, question (Advisor layer 3 includes the last advisor_history_size main decisions: choice, trade-off, outcome so far). `check_clean(text)` raises `PromptLeakError` on any banned word (whole word, case-insensitive) in any layer or schema string sent; B must check existing sense templates/action text for "game", "model" etc.
- Router (minds/router.py) `route(ctx, report) -> "reflex"|"fast"|"slow"|"hooked"`: (1) any `report.needs[n] >= urgent_levels[n]` and the reflex code (dummy needs logic) returns an action -> reflex, no call; (2) any taken interrupt kind in main_interrupts, or spoken_to from a player (not a villager), or a pending offer/trade/promise from a player -> main; main -> "hooked" if ctx.hooked else "slow"; (3) else fast (a lone 2-hour check is fast). A fast reply with `needs_more_thought=true` (the model says the choice cannot be undone or puts values in conflict) escalates to one main decision (slow/hooked by the same rule), recorded as that tier. A fast reply that proposes harm/promise/against stays fast and is recorded (C9 choice points).
