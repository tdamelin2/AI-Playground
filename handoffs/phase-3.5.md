# Phase 3.5: Observer comfort and the player guide
Status: Stage: Done | Round: 0/3 | Updated: 2026-11-03 12:46

## For Tim
This phase makes the watching screen easier to follow, at no cost and with no change to how the game plays. Each person gets a small bubble showing what they're doing (a picture, or a word like "Praying"). The Chats tab gets a village guide (who belongs to whom, in each player's colour) and filters (one village, one person, or what one person heard). You can hide the right-hand panel, drag the window to any size, press F11 for full screen, and pick a size and text scale from a Display menu; the program remembers your choice. Clicking a name or a person on the map selects them: the map follows them and an Inspector shows their needs, health, belongings and mood, with small graphs of wellbeing and trust. Important moments (a theft, a death, a land claim) flash on the map, and J jumps to the latest one. There is also a mini-map, an H key that lists every key, an F12 key that saves a picture, and a plain-language guide (docs/guide.md) to every command and picture.
How the work is split: two builders, as in Phase 3. One prepares the data the screen reads (and writes the guide); the other builds the screen. They agree up front on exactly what is passed between them.
From Codex we're taking: a correct way to measure gathering progress (my plan got it wrong), filling claimed land on the mini-map, fixing a small Phase 3 bug in the building progress bar, graph points only at real autosaves, one shared map-position calculation for clicks, rings and the mini-map, no screenshot when no named game is open, and not flashing old events when the window opens. You are approving the plan below.
