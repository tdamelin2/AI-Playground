## Findings
- Spec gap: the Inspector needs body, inventory, loyalty and bond data that WorldFrame doesn't carry (AgentView has only markers). phases.md says the Inspector reads "frame and database", so the frame must grow; added as defaulted AgentView fields (no snapshot change).
- Villagers have no ActiveAction; activity = job/idle/sleeping, progress 0. Night is the only villager sleep state available (Villager has no sleeping flag; `_agent_view` uses getattr).
- `structure_damaged` and `villager_left` events have no coordinates. Flash positions: building_damaged from the matching structure_built event; villager_departure from the villager's frame position. No event change (spec forbids).
- Filename example `p35_y1_w2_d3_14-05` uses day of week, but Clock.day is day of year (1..56); the Contract converts.
- Phase 3 `tab_text("Chats")` format is tested; keeping the guide in a separate element preserves it.
- Phase 3 Esc = quit (observer.py pump); kept.
- Panel width 480*ui can exceed the window at large ui choices (1280 with ui 3); the layout clamps ui.
- The guide must match three moving sources (argparse, key table, assets.toml); generating it avoids drift and makes AC-14 an equality test. The `guide` command is itself listed.
- Snapshots are plain JSON; trust/anger at `world.people.players[*]` (as measure/weekly.py reads ids). Pause/close snapshots also count as points (one per stored snapshot).
- `player_day` is emitted at day boundaries with exactly 24 hourly values (rules/turn.py:209-213).
- Viewer._window_size uses desktop minus margin; usable-desktop logic goes in observer (B) keeping the Viewer standalone fallback.

## Risks
- Observer size: observer.py is 526 lines and gains ~10 features. Mitigation: B splits into layout/keys/prefs/bubbles/inspector/graphs/minimap modules; delegated in 3 slices (B-01/02, B-03..05, B-06..09).
- Rebuilding pygame_gui elements on resize can lose state or leak elements: relayout must kill old elements; tested by AC-6 resize event.
- Fullscreen under the dummy driver: must not crash; test checks the flag.
- Frame build cost at 30 fps with the extra fields: small (4 players, <= 50 villagers); B-09 reports fps.
- Snapshot JSON parsing for graphs could stall frames: incremental cursor, parse only new snapshots.
- Determinism (AC-15): frame building must stay read-only (activity name lookup reads only). Phase 3 watched-vs-headless test reruns.
- Turn limits: slices of 2-5 Work IDs, Report-by-turn reminders.
