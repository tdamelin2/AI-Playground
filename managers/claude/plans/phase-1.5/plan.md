Status: Done | Started: 2026-11-02 08:48 | Finished: 2026-11-02 08:53

## Summary
- Replace the per-kind `animals_move` / `dogs_move` scheduler jobs with one `movement` job (every `movement_step_ticks`, default 1) in new `world/movement.py`. Each animal and dog carries its own mover state (next_move_tick, from/to, move_start/end, bout_left, fleeing, facing) saved in snapshots; due individuals are taken from an in-memory (due, id) heap rebuilt from entity state on load, so nothing extra is persisted and round trips stay exact.
- Wander = bouts of N tiles (uniform int in [bout_min, bout_max]) at `minutes_per_tile`, then rest (uniform int in [rest_min, rest_max]). Fleeing animals take a flee step at `flee_minutes_per_tile` when a dog is within `flee_radius` at a step decision. Dogs: own timers, cohesion step toward the pack leader, night/winter factors (<1) shorten minutes_per_tile and rest. A per-kind start cap per tick (`max_start_share`) guarantees AC-2.
- Snapshot version 2 (separate from the DB user_version, which stays 1).
- Clock: `daylight_at()` with new `dawn_minutes` / `dusk_minutes`; full dark exactly when `is_night` is true, so dogs are unchanged.
- WorldFrame: EntityView gains from/to/start/end/facing; frame gets `daylight`. CLI live loop passes `sub_tick`, subtracts draw time.
- Observer: two sheets (Kenney colour + Tiny Creatures tilemap), `palette = color|mono`, `[colors]`, `[light]`, ground colours, autumn variants, drought grass, one full-screen light layer, cached terrain layer, sliding sprites snapped to whole sprite pixels, flip by facing, fps in title.

## Findings
- Current movement: animals.run_animals_move moves each kind on one schedule (90-180 ticks) with move_chance; dogs.run_dogs_move moves whole packs every 20 ticks; both from the `animals` / `dogs` streams. This is exactly the lockstep the phase removes.
- engine.advance_to pops a (due, order, ident, seq) heap; a per-tick `movement` job adds ~80,640 pops per year, cheap. Rough step count: ~430 movers, ~4 steps per ~90-minute cycle -> ~1.5 M steps per year; a due-heap (not a scan of all movers per tick) keeps the full year well under 5 minutes (AC-7; Phase 1 was ~0.5 s).
- AC-2 is impossible for a kind with fewer than 4 individuals (one start is already > 25 %), and random timers alone would break it for goats (8) and boar (10): with independent timers, ~6 ticks per day would see 3 of 8 goats start together. Hence the deterministic start cap.
- storage/db.py uses SCHEMA_VERSION = 1 both for PRAGMA user_version and the snapshot column. Bumping it would make RunDB.open refuse the DB before the snapshot check runs, so the AC-6 refusal message would never be seen; a separate SNAPSHOT_VERSION keeps the DB schema stable (Overview: later phases add rows, not migrations).
- Kenney colored-transparent.png: 7 opaque colours (#cfc6b8 #bf7958 #e6482e #3cacd7 #7a444a #38d973 #f4b41b) plus transparency; colored.png background #472d3c is the 8th. White is not in the palette, so Phase 1 code art that uses white (snow dots, grass) needs a palette light colour in colour mode (code_light).
- Tiny Creatures ships `Tilemap/tilemap.png` (170x306 = 10 x 18 tiles of 16 px, 1 px gap, per Tilesheet.txt) and `Tiles/tile_0000..0179.png`; the sheet is used so the loader stays one mechanism. Sprites face right; flip when moving left (gameplay.md: sprites flip left/right). Sprites have their own dark outline colour (not a Kenney colour), which AC-12 allows.
- Tick 0 is 00:00, so `view --run t1 --ticks 720` is 12:00 and `--ticks 1320` is 22:00 for AC-16.
- Existing Phase 1 tests that will need updating by the tester: dog activity counters (test_p1_world.py AC-18), assets sheet / source checks (AC-19/20 now via mono), view/EntityView shapes.
- `new t1` refuses an existing run, so Tim's review step needs `runs\t1` deleted first.

## Risks
- AC-3 tolerance: blocked steps, flee steps and the start cap move the measured rate away from the formula 60 * mean_bout / (mean_bout * mpt + mean_rest). Mitigation: the tester measures over a full game week in summer daytime for animals, tolerance 20 %, and the formula is in the Contract.
- Ownership of config.py vs assets.toml (both parts touch the asset schema): AssetsConfig is frozen in the Contract and done first by coder-a (P1 lesson).
- Look on Tim's 3200x2000 screen at scale 3: coder-b looks at the screenshots (both palettes, noon and night) before reporting; manager looks too at verify.
- Snapshot round trip mid-step: the due-heap must be derived only from saved entity state; the tester's AC-6 test stops at a tick where some mover is mid-step.
