### Contract: frame data (A -> B)
All added records are frozen dataclasses containing only scalars/tuples/frozen records; no live Body, Inventory, ActiveAction, mutable dict or world references. Existing AgentView/WorldFrame constructor fields and defaults stay usable by earlier fixtures. World projection imports no pygame and emits nothing.
- AgentView appends activity: str = "idle", activity_target: str = "", activity_progress: float = 0.0, job: str | None = None, work_level: str | None = None.
- ACTIVITY_KINDS in world/view.py is sorted union of world.agents.ACTION_KINDS, JOBS, {"idle","sleeping"}; no independent hand-maintained vocabulary. Player with action uses request.kind, including rest; without action uses sleeping if actual sleeping flag else idle. Villager has no action or sleeping flag: use job when present, otherwise idle; do not invent a night sleeping flag. Villager job/work_level copy actual fields even when job=None.
- activity_target resolves existing state: for social/harm/care actions resolve data.target or request.target matching a person ID to its human name; for build/build_shrine/repair resolve numeric structure reference from data.structure/request.target to structure.kind, then request.structure (build_shrine fallback shrine); otherwise prefer resolved data.item then request.item, request.structure, resolved person name, empty. Never display a numeric structure ID as a person or turn a coordinate list into a name. Example gather(item=None) whose data.item="wood" -> gather/wood. Gift to player_2 named Ben -> gift/Ben. Build data.structure=7 with structure7.kind=house -> build/house.
- activity_progress is a clamped observation, never a wall-clock estimate. Walking move uses completed route edges plus existing movement fraction divided by route edge count; walking to work shows current travel stage. Working gather uses clamp((got + min(yield, max(0,want-got), carry_room)*u)/want), u=clamp(work_done/max(1,data.need)), using existing config gather_yield and data.want/got; carry_room=max(0, balance.actions.carry_limit-player.inventory.total_items()). Example with default wood yield4, ample carry room, want=8, got=0, work_done/need=0,0.5,1 -> 0,0.25,0.5; got=4 with same u=1 ->1. While gather walks/retargets hold got/want, so travel does not reset completed-quantity progress. Other working actions show clamped current work-unit fraction u; completed-unit time estimates are not inferred. Build may show clamp(structure.progress/buildings.work_minutes[kind]); do not reuse raw StructureView.progress, which currently clamps work-minute counts. Villager job uses clamp(work_acc/cycle_ticks); no job ->0. Idle/sleeping ->0. For Q01, verify 1.0 with detached ActiveAction endpoint fixtures; real completion switches immediately to idle/new action, as Phase 2 does.
- WorldFrame.village_guide defaults to VillageGuide(villages=(), wanderers=()). VillageGroup fields player_id, name, colour_index, villagers: tuple[PersonName(id,name),...]. All players appear sorted by id, members are living villagers with matching leader, sorted by id; wanderers are living villagers with leader=None. Names of dead people remain in existing frame.names for historic rows. Example villager_1 switches leader player_1->player_2: next frame removes it from group1 and adds to group2; no join/leave event needed for this projection.
- WorldFrame.inspectors: tuple[AgentDetails,...] = (). AgentDetails fields id, kind, name, leader_id, village_name, colour_index, alive, activity, activity_target, activity_progress, hunger, thirst, cold, rest, health, sickness, pain, feeling, wellbeing_x, hooked, items, tools, job, work_level, loyalty, bond. Common body values copy body; rest copies body.fatigue (label "Rest needed", not 100-fatigue). Player-only feeling/X/hooked reuse frame.panels computations; items is tuple of sorted (kind,count), tools tuple of (id,kind,tier,durability) sorted by id. Villager-only bond is bond[current leader] with configured bond_start_other fallback, or None if leader=None; no leader -> "Wanderers" and bond None. Inapplicable fields None/empty tuple. Example hunger12, fatigue23, health88, pain4 -> inspector values12,23,88,4 unchanged.
- WorldFrame.owned_tiles: tuple[(x,y,owner_index),...] = (), includes home interiors and all claims (home takes precedence), deterministic order. Existing borders are only edges and cannot fill minimap land.

### Contract: read model, chats and typed navigation (A -> B)

Person = speaker==id OR id in targets. Heard = selected_id in hearers only, no selection -> empty plus UI instruction.
