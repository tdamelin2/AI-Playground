## Summary
Replace species-wide movement checks with one pure-world movement job and saved individual journeys.
Commit tile coordinates only on arrival; use fractional game time only for drawing.
Use seeded staggering plus bounded step admission to meet the strict no-lockstep criterion.
Keep SQLite schema v1; independently version the changed snapshot payload as v2.
Load both local sheets, preserve their colours, and retain mono as a rendering option.
Cache terrain, draw clock-driven light once per frame, and measure real frame pacing.
Two acceptance ambiguities need explicit decisions at merge time; suggested resolutions follow below.
All implementation and validation are offline, cost $0; Codex has run no builds or tests.

## Proposed split
Coders: 2 - world/state/persistence and observer/assets/timing are separate, with one owner for shared config models.
Part A: deterministic movement, snapshots, immutable view contract and all config models | Folders: src/ai_island/world/, src/ai_island/sim.py, src/ai_island/config.py, config/world.toml, config/balance.toml
Part B: colour manifest, sprite loader, cached viewer, daylight and live-loop pacing | Folders: src/ai_island/observer/, src/ai_island/cli.py, config/assets.toml, config/run.toml
Contract:
- A alone edits config.py, including asset/view models required by B. Agree these fields before parallel implementation. B alone edits assets.toml/run.toml and CLI. No dependency change is needed.
- Animal/Dog retain their existing positional constructor prefix and committed x/y. Append defaulted movement fields: from_x/from_y, to_x/to_y, move_start_tick/move_end_tick, next_move_tick, bout_remaining. Initialize idle coordinates to current position, start=end=current tick; stationary nests have no due move. Preserve every field, scheduler entry, aggregate counter and RNG position in JSON snapshots.
- Pure movement.py primitives: begin_step(entity, destination: tuple[int,int], tick: int, duration: int) -> None; complete_step(entity, tick: int) -> bool. begin_step does not change x/y; completion at T+duration commits to_x/to_y exactly once. These primitives accept a destination and duration independently of animal policy, so Phase 2 can supply routes and terrain-adjusted walk durations.
- Exactly one recurring movement job replaces animals_move/dogs_move; movement_step_ticks=1 in balance.toml and validation requires 1 for this phase. At each tick complete due journeys first; then consider due starts in global entity-id order. Adjacent legal targets respect animal habitat+zone and dog passability+no-home constraints. Sample from valid neighbours to avoid wasting most bouts at boundaries; no legal target means a bounded retry, no completed tile.
- Stagger initial, newborn and recolonised movers through animals/dogs RNG streams after map placement, without changing the equal rotated home layout. Newborn initialisation occurs at birth, not from a renderer or a later global reset. Keep breeding/extinction/season schedules; preserve dog pack identity and cohesion policy while giving each dog its own timer.
- Enforce per-kind starts/tick <= floor(N/4) for N>=4, counting dogs as one kind across packs and animals globally across zones. Defer excess unstarted steps to tick+1; never postpone an existing completion. Proposed N<4 exception: permit one start/tick (P1.5-Q-CDX-01). No added per-step event rows.
- balance.toml moving kinds require positive minutes_per_tile, bout_tiles_min/max, rest_minutes_min/max; flee_minutes_per_tile is additionally required and strictly shorter where flees_dogs=true. Reject missing/nonpositive values, inverted ranges and unsupported movement cadence with file+dotted key. Remove obsolete movement interval/chance keys; nests are explicitly stationary and exempt from moving-kind fields.
- Starting tuning: rabbit 3/flee1, deer 3/flee1, boar5, goat6/flee3, chicken6/flee3, bird2/flee1, fish8 minutes/tile; dogs4. All initially use bouts2..6 and rest20..120, each key with a reason comment. This gives active rabbit/deer steps about1.08 real seconds at x1; longer steps deliberately distinguish heavier/slower kinds. Existing dog multipliers night2.5/winter1.6 divide BOTH duration and rest, rounded up to whole minutes with minimum1; day4 becomes night2. Freeze duration at step start. Resting fleeing animals can react on movement ticks; a begun journey retains its promised end tick.
- WorldFrame EntityView adds from_x/from_y/to_x/to_y/move_start_tick/move_end_tick for all entities; idle/static entries use identical endpoints. WorldFrame also carries ticks_per_day, night_start_hour, night_end_hour, dawn_minutes and dusk_minutes copied from sim.config.world.clock, so saved runs use pinned clock settings. All fields are immutable values.
- Viewer.draw(frame, sub_tick=0.0, measured_fps=0.0) remains callable with only frame. Live sub_tick is fractional tick debt, not journey progress: p=clamp((frame.tick+sub_tick-start)/(end-start),0,1), with an explicit idle branch. Round the interpolated position in native 16px sprite pixels, then multiply by integer scale and add viewport offsets; cull using the interpolated sprite rectangle. Journey endpoints/midpoint and successive tick boundaries get separate tests (P1.5-Q-CDX-02).
- AssetsConfig: palette=color|mono (default color), sheets.kenney and sheets.tiny_creatures, items.source=kenney|tiny_creatures|code, existing col/row/flip fields, missing.items. Use sheet crops for this installed pack; no separate-file mode is needed here. Keep all 126 existing item keys. Require missing.items to equal the set of code-source keys.
- B records the eight Kenney palette hex values extracted from the local colour sheet in assets.toml and A validates hex format and completeness. Tables colors.ground cover all TERRAIN_KEYS; colors.player cover player_1..player_4 with distinct colours; colors.ink cover missing.items; background=#472d3c. Store seasonal colours and light tint/alpha tunables in assets.toml as well. Code drawings and Kenney sprites use the eight-colour set before compositing; Tiny Creatures keeps its own colours. Mono converts every loaded sprite to black/white/binary transparency.
- New clock dawn_minutes=60 and dusk_minutes=60 have reason comments and positive/non-overlap validation. Proposed visual dawn starts at night_end_hour (06:00..07:00 default), dusk at night_start_hour (20:00..21:00), with the darkest plateau from end of dusk to start of dawn and no daylight tint at noon in clear weather. Use a monotone smoothstep curve and one full-window tint surface; rain/storm add configured darkness. is_night_at/is_night_hour are unchanged.
- SNAPSHOT_VERSION=2 lives in sim.py, separate from storage.db.SCHEMA_VERSION=1. Both snapshot.schema_version and state JSON schema use2. Reject incompatible snapshots with found/expected versions before pinned config parsing or World.from_state. No SQL/table migration and no rewriting old runs.
